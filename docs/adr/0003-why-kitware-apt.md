# 0003. CMake из Kitware APT вместо apt/pip

> **Статус:** Superseded by [ADR-0004](0004-why-cmake-binary-archive.md)
>
> Это историческая запись. Изначально решение было — использовать Kitware APT
> репозиторий. В процессе эксплуатации выяснилось, что `apt.kitware.com`
> нестабилен в CI (пустые ответы, транзиентные 5xx). Решение заменено на
> установку CMake из бинарного архива GitHub — см. ADR-0004.
