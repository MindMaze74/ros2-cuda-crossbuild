## Что такое ADR

ADR — короткая записка на 1–2 страницы, которая фиксирует:

- **Контекст** — какая задача стояла и какие были ограничения.
- **Рассматриваемые варианты** — что ещё можно было сделать.
- **Решение** — что выбрали и почему.
- **Последствия** — плюсы, минусы, ограничения.

ADR не переписываются задним числом. Если решение меняется — создаётся
новый ADR со статусом `Superseded by NNNN`. Старые остаются как история.

## Как добавить новый ADR

1. Скопируйте `0001-why-qemu.md` как шаблон.
2. Назовите файл `NNNN-краткое-название.md`, где `NNNN` — следующий номер.
3. Заполните четыре секции: Контекст / Варианты / Решение / Последствия.
4. Добавьте строку в таблицу выше.
5. Закоммитьте вместе с PR, где применяется решение.
