# 0002. ROS2 Jazzy на Orin Nano вместо Humble

## Контекст

Базовый образ Nano построен на `nvidia/cuda:12.6.3-devel-ubuntu24.04` (Ubuntu 24.04).
ТЗ предполагает ROS2 Humble для всех платформ.

## Проблема

ROS2 Humble официально поддерживает **Ubuntu 22.04**. Для Ubuntu 24.04 бинарных
пакетов Humble нет. Собрать из исходников теоретически можно, но:

- это десятки зависимостей, часть из которых тоже придётся собирать из исходников;
- сборка из исходников Humble на 24.04 не поддерживается upstream — гарантий
  совместимости нет;
- время сборки базового образа вырастает с 15 минут до нескольких часов.

## Рассматриваемые варианты

1. **Ubuntu 22.04 + Humble на Nano.**
   Минусы: официальный образ `nvidia/cuda:12.6.3-devel-ubuntu24.04` под Nano
   рассчитан на 24.04 (JetPack 7). Откат на 22.04 ломает совместимость с драйвером
   и CUDA-стеком JetPack 7.

2. **Ubuntu 24.04 + Jazzy на Nano.**
   Плюсы: Jazzy — LTS, официально поддерживает 24.04, бинарные пакеты есть.
   Минусы: отличие от Humble по API (в части ROS2-пакетов), не соответствует
   букве ТЗ.

3. **Собрать Humble из исходников на 24.04.**
   Минусы: часы сборки, непредсказуемые ошибки совместимости.

## Решение

**Ubuntu 24.04 + ROS2 Jazzy** для Nano (вариант 2).

Jazzy — LTS-релиз, вышедший в мае 2024, поддерживается до 2029.
Для FAST-LIO2 API-различия минимальны — код работает с `rclcpp` и `sensor_msgs`,
которые между Humble и Jazzy совместимы.

## Последствия

- Nano-образ собирается без костылей.
- Jazzy — актуальный LTS.
- Отклонение от ТЗ («ROS2 Humble для всех платформ»). В отчёте
  зафиксировано явно.
- Если пакет использует Humble-специфичные API — на Nano он не соберётся.
  В `config/packages.yaml` поле `ros_distro` задаётся per-package.
